如何比較兩個版本

  1. 將原版本與新版本貼到輸入區。任一側可以留空。
  2. 按「比較文字」，查看每一行的新增、移除與保留，以及兩側行號。
  3. 用上一頁／下一頁閱讀全部結果，或下載純文字閱讀報告。

工具只比較，不會合併或修改原文。交換版本只會互換原文；編輯任一側會清除舊結果，需要重新比較。取消會保留兩份原文。

比較規則與上限

CRLF 和單獨的 CR 先轉成 LF，其餘字元不變。完整行精確相等才視為保留；多條最佳比對路徑等長時，優先移除原版本行。替換顯示為先移除、再新增。

每側原始文字的 UTF-8 上限是 131,072 bytes（128 KiB），UTF-16 長度也不得超過 131,072。轉換換行後最多 1,000 行，每行最多 8,192 個 UTF-16 單位；一個字元可能占多個 bytes 或單位。超限會停止整次比較，不截斷貼上的文字。

最多 2,000 筆結果，每頁 100 筆，不折疊保留行。運算超過 5 秒即停止；下載報告上限 512 KiB。

常見問題

為什麼只多一個換行也有差異？

最後的 LF 代表最後一個空行，會作為差異顯示。CRLF 和 LF 會先統一，所以換行種類本身不算差異。空字串是 0 行；一個 LF 則是兩個空行。

可以忽略空格或大小寫嗎？

目前按完整行精確比對，空格、Tab 和大小寫都保留。不會自動 trim 或改寫字元。

下載報告能套用到 Git 嗎？

不能。它是帶新增／移除前綴的閱讀報告，沒有 patch 檔的套用資訊。保留行前面有兩個空格，移除行是「- 」，新增行是「+ 」。

可以比較很大的檔案嗎？

每側上限 128 KiB、1,000 行，每行 8,192 個 UTF-16 單位。超過時請分段處理；本工具沒有檔案上傳功能。

本頁的資料處理

文字在你的瀏覽器記憶體中比較，不保存歷史、不寫入本機儲存空間、不傳送文字供遠端處理。頁面與程式等網站資源仍需載入；載入完成後可離線比較，關閉後離線重新開啟尚未保證。

「全部清除」會移除本頁持有的來源與結果並停止運算，不會刪除已下載的檔案，也不宣稱安全抹除瀏覽器或作業系統記憶體。切換語言會開啟另一頁並清除目前工作。
